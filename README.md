# E-Commerce-Sales-Orders-Analysis-2025
📊 An interactive E-Commerce Sales &amp; Orders Analysis Dashboard (2025) built using Microsoft Excel to analyze sales performance, track order status, identify top-performing states and sales channels, and visualize customer purchasing trends using Pivot Tables, Pivot Charts, and interactive filters.

• Men vs Women Sales Analysis

• Maharashtra recorded the highest sales among the Top 10 states shown.
